# Agave

> Agave is a unified API for the construction industry: one REST contract to read and write data
> across 100+ construction and accounting systems — Procore, Autodesk Build, QuickBooks, Sage,
> Viewpoint, Acumatica, Foundation, CMiC, ServiceTitan and more. Agave normalises projects, budgets,
> contracts, commitments, purchase orders, invoices, payments, cost codes, vendors, timesheets and
> files into one model, brokers the source-system OAuth through a hosted Link component, and layers
> AP automation, expense management, AI analytics and an MCP server on top.

## What you need to know before calling it

- Base URL: https://api.agaveapi.com — there is NO /v1 prefix and NO sandbox host.
- `API-Version: 2021-11-21` is required on every request; omitting it returns 401.
- Auth is three static headers, not OAuth: `Client-Id` (36-char UUID), `Client-Secret` (40-char
  string), and `Account-Token` (per linked customer account). Issued by api-support@agaveapi.com.
- OAuth exists one layer down: Agave Link performs it against the source system and returns an
  Account-Token. There are no scopes on Agave's own API.
- Pagination: `page` + `per_page` (max 1000); keep paging until `meta.has_more_results` is literally
  `false` — some source systems return `null`, which does not mean done.
- Errors are `{"message": "..."}` or `{"error": "..."}` — not RFC 9457, and there is no error code.
- Rate limits: 150 requests/minute per linked account plus the source system's own; read
  `Agave-RateLimit-Remaining` and `{SourceSystem}-RateLimit-Remaining`. 429 on exhaustion, no
  Retry-After.
- Writes are effectively irreversible through Agave — no undo, void or reversal operation and no
  stated reversal window.

## APIs

- [Agave Unified Construction API](https://docs.agaveapi.com/): one REST API over 100+ construction
  and accounting systems. Base https://api.agaveapi.com
- [Agave Link](https://docs.agaveapi.com/agave-link/quickstart): hosted front-end component that
  handles source-system authentication and returns an Account-Token.
- [Agave MCP](https://useagave.com/agave-mcp): read-only MCP server exposing ERP and PM data to
  ChatGPT, Claude and Microsoft Copilot. Endpoint is not published; provisioned through sales.
